## Educational shopping demo

Independent learning project by Saikat Ghosh, not affiliated with or endorsed by Amazon. All shopping, orders, delivery dates and payments shown are simulated. Do not enter personal, account or payment information. Demo orders use the public SuperSimple backend test service; this is not a real store.

A prominent educational notice is included on every shopping, checkout, orders and tracking page.

<a href="https://saikat-ghosh-in.github.io/amazon-replica/">version1</a> is complete (few buttons might not work in this version)

<br>This application is built with HTML, CSS and JavaScript.
